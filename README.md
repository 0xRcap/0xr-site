# innie

A boutique creative studio that builds digital universes for brands. An **innie** is a
digital character with a soul — canon, taste, memory, and a public track record — that
makes the brand's content and, in time, distributes it.

Read in this order: [INNIE.md](./INNIE.md) (the studio's constitution) →
[SOUL.md](./SOUL.md) (how a soul is written) → `souls/` (the characters).

The intelligence layer is [HEAT](../heat/) — the culture & attention engine. It stays
its own machine; innie consumes its opportunities (`:8972/api/briefs`) and gives them
a voice.

```
npm install
npm run voice -- souls/house.soul.md        # voice the open HEAT opportunities
```
