# Rehearsal — 2026-07-19, AMZNx (expired brief)

*A rehearsal, not a ledger entry: the pipeline run end-to-end on an already-expired
brief (`brief_8e82b109bda9`, "AMZNX IS CROSSING SURFACES RIGHT NOW") to validate the
roles before the first real run. Runtime: Claude subagents driven with the exact
prompts `--harness` mode emits — same prompts the production API path uses.*

## Round 1 — voice ungrounded

The voice produced 3 in-character variants. **The editor killed all three, for the
same defect: an invented timestamp** ("Flagged 2026-07-18") — the soul's law says
every early call carries its timestamp, but the pipeline never *gave* the voice one,
so it made one up.

**Finding 1:** a law the pipeline makes impossible to follow is a bug in the
pipeline, not the character. → `FLAGGED: <ISO>` line added to the voice prompt from
the brief's `createdAt`.

**Finding 2:** an editor blind to the opportunity's facts can only kill invented
data by luck. Its blindness must be selective — blind to the *excitement*, sighted
on the *measured facts*. → `permittedFacts()` added; the editor receives the exact
list and treats any other number/date as an automatic kill.

## Round 2 — voice grounded

3 new variants, all carrying `flagged 2026-07-16T04:02:52Z` correctly.

| # | Verdict | Editor's reason |
|---|---------|-----------------|
| 0 | **PASS** | Surfaces, heat, timestamp all measured; register holds; closes clean. |
| 1 | KILL | Mislabeled the echo surfaces ("crypto scene, stocks current" as the echo; "the wires" unmeasured). |
| 2 | KILL | Overstated the record fact; leaned on the method slogan instead of the finding. |

The passing draft:

> AMZNx, named on two surfaces — the wells and the commons — while the record stays
> silent. Heat 78/100 in the stocks current. Flagged 2026-07-16T04:02:52Z. When the
> record finally prints, the timestamp will show who was watching.

**Finding 3:** `scene`/`current` are shown to the voice but weren't in the permitted
facts, so the editor part-killed draft 1 on data that was actually measured. →
`permittedFacts()` now includes them.

## Verdict on the system

- The voice holds character under real engine data.
- The adversarial editor is worth its cost: it caught a systemic fabrication no
  style check would see, and its kill rate (⅔) is the anti-slop margin working.
- Pass rate of 1-in-3 per opportunity is fine — the pipeline asks for 3 variants
  precisely so the editor can be brutal.

First *ledgered* run happens on the next open brief the engine produces.
